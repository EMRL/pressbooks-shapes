# Pressbooks Shapes

Pressbooks Shapes is a browser-based tool for creating vector forms.
The first tool creates a radial shape with repeated petals.

## Run locally

Open the index.html file in a modern browser.
The app does not require a build step or package installation.

## Radial generator

Adjust petal count, core size, petal width, tip roundness, variation, and rotation.
Change the fill color or include a white background.
The preview updates when you change a control.

The seed creates repeatable variation.
Select the refresh button to create a new seed.
Use the same seed and settings to recreate a shape.

Select **Download SVG** to save the current shape.
The file uses a 600 by 600 viewBox.
The SVG background stays transparent unless you enable the background control.
